# Учебный frontend-проект

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина.

## Ссылка на опубликованный проект

GitHub Pages: https://zchuby.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — страница каталога;
- `product.html` — страница товара с характеристиками;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и форма обратной связи;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и проверка форм;
- `images/` — изображения товаров;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (минимально: модальное окно и проверка форм);
- Git;
- GitHub.

## Инструкция по просмотру

1. Открыть сайт по ссылке GitHub Pages.
2. Перейти в разделы меню: Каталог, Заявка, Контакты.
3. Из каталога перейти на страницу товара.
4. На странице товара нажать «Быстрый заказ» — откроется модальное окно.
5. Заполнить и отправить форму заявки.

## Самостоятельные доработки

- добавлены хлебные крошки на внутренних страницах;
- блок отзывов на странице товара;
- раздел «Частые вопросы» на странице контактов;
- фиксированная кнопка «Наверх»;
- sticky-блок фильтров в каталоге;
- активный пункт меню на текущей странице;
- подсветка карточек товаров при наведении.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.

- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: проверена многостраничная структура, добавлены якорные ссылки в навигацию, плавная прокрутка и подсветка цели якоря.
- Практическая работа 6: навигация доработана через Flexbox, карточки и страница каталога организованы через CSS Grid с именованными областями.

## Использование Flexbox и Grid

- Flexbox для основного меню и шапки сайта;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек товаров;
- CSS Grid для страницы каталога с фильтрами и списком товаров (grid-template-areas).

## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `product-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters` — форма фильтров;
- `order-form` — форма заявки;
- `order-dialog` — модальное окно быстрого заказа;
- `review` — отзыв на товар;
- `contacts` — блок контактов;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.
