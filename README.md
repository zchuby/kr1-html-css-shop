# Учебный frontend-проект

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт фотостудии «Ракурс»:
15 залов в трёх локациях Москвы, страницы залов, бронирование и контакты.

## Ссылка на опубликованный проект

GitHub Pages: https://zchuby.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — все залы (15 залов в трёх локациях);
- `category.html` — страница локации «Преображенская площадь»;
- `product.html` — страница зала «Воздух» с характеристиками;
- `order.html` — форма бронирования зала;
- `contacts.html` — адреса локаций, частые вопросы и форма обратной связи;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и проверка форм;
- `images/` — фотографии залов;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (минимально: модальное окно и проверка форм);
- Git;
- GitHub.

## Инструкция по просмотру

1. Открыть сайт по ссылке GitHub Pages.
2. Перейти в разделы меню: Наши залы, Бронирование, Контакты.
3. Из каталога перейти на страницу зала.
4. На странице зала нажать «Быстрая бронь» — откроется модальное окно.
5. Заполнить и отправить форму бронирования.

## Самостоятельные доработки

- добавлены хлебные крошки на внутренних страницах;
- блок отзывов на странице зала;
- раздел «Частые вопросы» на странице контактов;
- фиксированная кнопка «Наверх»;
- sticky-блок фильтров в каталоге;
- активный пункт меню на текущей странице;
- подсветка карточек залов при наведении;
- страница отдельной локации `category.html` со своей навигацией и блоком ссылок на другие локации;
- расширенный каталог: 15 залов в локациях «Бауманская», «Дмитровская» и «Преображенская площадь», у карточек подписи локаций, кнопки «Забронировать» и зачёркнутая старая цена у скидки;
- варианты карточек через БЭМ-модификаторы: `product-card--hit`, `product-card--featured`, `product-card--new`, `product-card--discount`, `product-card--out-of-stock`;
- дополнительные состояния кнопок и карточек: `:active` у кнопок, вторичный вариант `button--secondary`, отключённое состояние `button--disabled`, подъём и тень карточки при наведении, `:focus-within` для навигации с клавиатуры, поддержка `prefers-reduced-motion`;
- подробная карточка зала: галерея с миниатюрами, артикул, наличие, список особенностей, выбор количества часов;
- таблица характеристик зала на странице `product.html`;
- улучшенное модальное окно быстрой брони: показывает выбранный зал, закрывается по клику на затемнение, фокус переходит на первое поле;
- улучшенная доступность форм: обязательные поля отмечены звёздочкой, подсказки связаны через `aria-describedby`, тексты ошибок появляются при проверке, сообщение об отправке объявляется скринридером через `aria-live`.

## Использование Flexbox и Grid

- Flexbox для основного меню и шапки сайта;
- Flexbox для внутренней структуры карточек залов;
- CSS Grid для сетки карточек залов;
- CSS Grid для страницы каталога с фильтрами и списком залов (grid-template-areas).

## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `product-grid` — сетка залов;
- `product-card` — карточка зала (модификаторы `--hit`, `--featured`, `--new`, `--discount`, `--out-of-stock`);
- `category-links` — ссылки на другие локации на странице категории;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters` — форма фильтров;
- `order-form` — форма бронирования;
- `order-dialog` — модальное окно быстрой брони;
- `review` — отзыв о зале;
- `contacts` — блок контактов;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:active`, `:disabled`, `:focus-within`;
- отключение анимаций при `prefers-reduced-motion`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.
