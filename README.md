# Учебный проект «Гардероб»

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка», МИРЭА, ИПТИП, 3 семестр 2026/2027 уч. года.

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина одежды.

## Ссылка на опубликованный проект

GitHub Pages: https://zchuby.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог товаров с фильтрами и категориями;
- `product.html` — карточка товара: описание, таблица характеристик, отзывы, быстрый заказ;
- `order.html` — форма оформления заявки;
- `contacts.html` — контактная информация, FAQ и форма обратной связи;
- `css/style.css` — общий файл стилей;
- `js/main.js` — минимальная логика: модальное окно, валидация форм, кнопка «Наверх»;
- `images/` — SVG-иллюстрации товаров;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, позиционирование, состояния);
- JavaScript (только для модального окна, валидации форм и кнопки «Наверх»);
- Git и GitHub.

## Инструкция по просмотру

1. Открыть ссылку GitHub Pages, указанную выше.
2. Перейти из меню в разделы: Каталог, Заявка, Контакты.
3. Из каталога открыть карточку товара «Подробнее».
4. На странице товара нажать «Быстрый заказ» — откроется модальное окно.
5. Заполнить форму заявки на странице order.html и отправить.

## Описание обязательных страниц

| Страница | Содержание |
| --- | --- |
| index.html | Hero-блок, 4 преимущества, 3 популярных товара, информационный блок |
| catalog.html | Статический блок фильтров (sticky), 8 карточек товаров с бейджами |
| product.html | Хлебные крошки, изображение, описание, таблица характеристик, отзывы, модальное окно быстрого заказа |
| order.html | Полная форма заявки: имя, e-mail, телефон, дата, товар, комментарий, согласие |
| contacts.html | Контактная информация, FAQ, форма обратной связи |

## Самостоятельные доработки

- собственная визуальная концепция: тёплая палитра (крем, тёмно-зелёный, терракота) и серифная гарнитура заголовков на CSS-переменных;
- расширенный каталог: 8 товаров, три категории в фильтрах, бейджи «Хит», «Новинка», «Скидка»;
- хлебные крошки на внутренних страницах;
- блок отзывов покупателей на странице товара;
- раздел «Частые вопросы» (details/summary) на странице контактов;
- фиксированная кнопка «Наверх» на всех страницах;
- sticky-блок фильтров в каталоге;
- активный пункт меню через БЭМ-модификатор `site-nav__link--active`;
- собственные SVG-иллюстрации товаров вместо внешних изображений;
- модальное окно быстрого заказа с подстановкой выбранного товара;
- простая адаптивность сеток на узких экранах;
- подробный README со структурой и инструкцией.
